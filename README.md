# TechNova — сучасний онлайн-магазин товарів, що допомагають у житті

Проєкт побудований на **Next.js 14**, **TypeScript** та **Tailwind CSS 4**. Магазин містить каталог із 20 товарами, кнопку оплати через Prom.ua, обовʼязкові сторінки для Google Ads та SEO-налаштування.

## Основні можливості
- Головна сторінка з промо-блоком, CTA та добіркою популярних товарів.
- Каталог з картками товарів, цінами у гривнях та кнопкою «Купити на Prom.ua».
- Статичні сторінки: `Доставка`, `Повернення товару`, `Конфіденційність`, `Публічна оферта`, `Контакти`.
- Дані про товари зберігаються у `data/products.json` з посиланнями на Prom.ua та локальними зображеннями з `public/images`.
- Автоматична генерація `sitemap.xml` і `robots.txt` через **next-sitemap**.
- Готова конфігурація для деплойменту на **Vercel** (`vercel.json`).

## Структура проєкту
```
.
├── data/products.json        # Плейсхолдери товарів
├── public/images/            # Статичні зображення
├── src/app/                  # App Router, сторінки та layout
├── src/components/           # UI-компоненти (Header, Footer, ProductCard)
├── next-sitemap.config.js    # Конфігурація карти сайту та robots.txt
└── vercel.json               # Налаштування для Vercel
```

## Запуск локально
```bash
npm install
npm run dev
```
Після запуску додаток буде доступний на [http://localhost:3000](http://localhost:3000).

## Продакшн-збірка та генерація sitemap
```bash
npm run build
```
Команда виконає продакшн-збірку і автоматично згенерує `public/sitemap.xml` та `public/robots.txt`. За потреби їх можна згенерувати вручну:
```bash
npm run sitemap
```

## Змінні середовища
- `SITE_URL` — публічна адреса магазину (наприклад, `https://technova.ua`). Використовується для генерації `sitemap.xml` та `robots.txt`.
- `NEXT_PUBLIC_SITE_URL` — те саме значення для метаданих Open Graph та canonical-посилань.

> **Порада:** налаштуйте обидві змінні у Vercel Dashboard перед деплойментом, щоб у файлах sitemap та metadata відображалась коректна адреса.

## Деплоймент на Vercel
1. Створіть новий проєкт на [vercel.com](https://vercel.com/).
2. Додайте змінні `SITE_URL` і `NEXT_PUBLIC_SITE_URL`.
3. Запустіть деплой — Vercel автоматично викличе `npm run build`, а після збірки згенерує `sitemap.xml` та `robots.txt`.

## Корисні команди
- `npm run dev` — режим розробки.
- `npm run build` — продакшн-збірка.
- `npm run start` — запуск продакшн-збірки локально.
- `npm run lint` — перевірка коду.
- `npm run sitemap` — ручна генерація SEO-файлів.
