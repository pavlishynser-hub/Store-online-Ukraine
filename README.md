# AutoComfort Hub — лендінг автоаксесуарів

Невеликий промо-сайт для магазину автоаксесуарів, зібраний на **Next.js 14**, **TypeScript** та **Tailwind CSS 4 (mobile-first)**. Проєкт складається з головної сторінки з 4 товарами та шаблонної сторінки товару з формою заявки без бекенда.

## Особливості
- Головна `/` з компактними картками товарів, CTA, блоком переваг та фіксованою панеллю соцмереж.
- Динамічна сторінка `/product/[slug]` з описом, ціною, bullet-списком плюс інтерактивна форма «Оформлення замовлення».
- Статичні дані зберігаються у `data/products.ts`, тип `Product` описано в `src/types/product.ts`.
- Весь інтерфейс українською мовою, кольорова схема та компоненти підігнані під мобільний сценарій.
- Готова конфігурація для деплою на **Vercel** (див. `vercel.json`).

## Структура проєкту
```
.
├── app/                      # App Router сторінки
│   ├── page.tsx              # Лендінг з картками
│   └── product/[slug]/       # Шаблон сторінки товару
├── data/products.ts          # Дані 4 товарів
├── public/images/            # Плейсхолдери зображень
├── src/components/
│   ├── ProductCard.tsx       # Картка товару на головній
│   └── OrderForm.tsx         # Форма оформлення замовлення
├── src/types/product.ts      # Типізація Product
└── app/globals.css           # Tailwind + базові стилі
```

## Запуск локально
```bash
npm install
npm run dev
```
Після запуску перейдіть на [http://localhost:3000](http://localhost:3000).

## Продакшн-збірка
```bash
npm run build
```
Якщо потрібен превʼю продакшну:
```bash
npm run start
```

## Корисні команди
- `npm run dev` — режим розробки.
- `npm run build` — продакшн-збірка.
- `npm run start` — запуск продакшн-білду.
- `npm run lint` — перевірка ESLint.
