## NovaStore — онлайн-магазин українською

Повноцінний інтернет-магазин на Next.js 14 (TypeScript + Tailwind CSS) з інтеграцією кнопок покупки на Prom.ua та сторінками для модерації Google Ads.

### Основні можливості
- 💎 Сучасний адаптивний дизайн з Tailwind CSS
- 🛍️ Каталог із 15 товарами та сторінками товарів
- 💳 Кнопки “Купити на Prom.ua” для кожного товару
- 📄 Обов’язкові сторінки: доставка, повернення, конфіденційність, публічна оферта, контакти
- 🔍 SEO: кастомні метадані, sitemap, robots.txt (next-sitemap), OpenGraph
- 🚀 Готовність до деплою на Vercel (включно з `vercel.json`)

---

### Структура проєкту
- `src/app` — сторінки Next.js (App Router)
- `src/components` — UI-компоненти (Hero, Header, Footer, картка товару)
- `src/lib` — робота з даними та утиліти
- `data/products.json` — каталог товарів з посиланнями на Prom.ua
- `public/images` — статичні зображення товарів (SVG-заглушки)

---

### Швидкий старт
1. **Встановіть залежності**
   ```bash
   npm install
   ```
2. **Запустіть dev-сервер**
   ```bash
   npm run dev
   ```
3. Відкрийте [http://localhost:3000](http://localhost:3000) у браузері.

---

### Збірка та генерація sitemap
- `npm run build` — продакшн-збірка Next.js
- `npm run postbuild` — автоматичний запуск `next-sitemap` після зборки
- `npm run lint` — перевірка ESLint

---

### Змінні середовища

| Змінна | Опис | Приклад |
| --- | --- | --- |
| `NEXT_PUBLIC_SITE_URL` | Базова адреса сайту для генерації sitemap та метаданих. | `https://store-yourbrand.vercel.app` |

> Якщо змінну не вказати, буде використано `https://novastore-shop.vercel.app`.

---

### Деплой на Vercel
1. Створіть новий проєкт на [vercel.com](https://vercel.com).
2. Підключіть репозиторій і оберіть фреймворк **Next.js**.
3. У налаштуваннях “Environment Variables” додайте `NEXT_PUBLIC_SITE_URL`.
4. Деплой проходить командою `npm run build` (визначено у `vercel.json`).

---

### Кредит
Проєкт створено спеціально для демонстрації інтеграції Prom.ua та відповідає вимогам модерації Google Ads. Весь вміст можна вільно змінювати під власний бренд.
