# Nova Market — онлайн-магазин з інтеграцією Prom.ua

Сучасний інтернет-магазин, побудований на **Next.js 14 + TypeScript + Tailwind CSS**, з повною україномовною локалізацією, SEO-оптимізацією та необхідними сторінками для модерації Google Ads. Кожен товар має кнопку «Купити на Prom.ua», що перенаправляє на безпечне оформлення замовлення.

## Основні можливості

- 📱 Адаптивний дизайн: зручний перегляд на мобільних, планшетах та десктопах.
- 🛒 Каталог з пошуком і фільтрами за категоріями.
- 🛍️ 20 готових товарів у `data/products.json` із посиланнями на Prom.ua.
- 📄 Обов’язкові сторінки: доставка, повернення, конфіденційність, публічна оферта, контакти.
- 🔍 SEO: кастомні метадані, `next-sitemap`, `robots.txt`, готовність до Google Ads.
- 🚀 Готовність до розгортання на Vercel з `vercel.json`.

## Технології

- [Next.js 14 (App Router)](https://nextjs.org/)
- [TypeScript](https://www.typescriptlang.org/)
- [Tailwind CSS (v4 preview)](https://tailwindcss.com/)
- [next-sitemap](https://github.com/iamvishnusankar/next-sitemap)

## Структура проєкту

```
app/                # Сторінки та маршрути (App Router)
  catalog/          # Каталог із фільтрами та сторінки товарів
  delivery/         # Сторінка доставки
  return-policy/    # Політика повернення
  privacy/          # Політика конфіденційності
  terms/            # Публічна оферта
  contacts/         # Контакти
components/         # Повторно використовувані компоненти інтерфейсу
data/products.json  # Список товарів з описами та посиланнями Prom.ua
public/images/      # Статичні зображення (банер, продукти, логотип)
next-sitemap.config.js
vercel.json
```

## Початок роботи

1. Встановіть залежності:

   ```bash
   npm install
   ```

2. Запустіть середовище розробки:

   ```bash
   npm run dev
   ```

3. Відкрийте [http://localhost:3000](http://localhost:3000) у браузері.

## Змінні оточення

- `NEXT_PUBLIC_SITE_URL` — базова адреса сайту (потрібно для коректного формування sitemap та метаданих).  
  За замовчуванням використовується `https://nova-market-store.vercel.app`.

## Команди

- `npm run dev` — запуск у режимі розробки.
- `npm run lint` — перевірка коду ESLint.
- `npm run build` — продакшн-збірка Next.js.
  - Після збірки автоматично виконується `next-sitemap` (`npm run postbuild`).
- `npm start` — запуск продакшн-збірки локально.

## Розгортання на Vercel

1. Створіть новий проєкт на [Vercel](https://vercel.com/).
2. Під час налаштування вкажіть репозиторій GitHub та задайте змінну `NEXT_PUBLIC_SITE_URL`.
3. Додаткові налаштування:
   - Framework: **Next.js**.
   - Output Directory: **.next** (вже налаштовано у `vercel.json`).
4. Після першого деплою перевірте наявність файлів `sitemap.xml` та `robots.txt` у корені сайту.

## Наповнення товарами

- Редагуйте файл `data/products.json`, щоб додати реальні позиції (мінімум 15 товарів).
- Для кожного товару можна використовувати власні зображення у каталозі `public/images/products`.
- Посилання `promLink` мають вести на конкретні сторінки вашого магазину на Prom.ua.
